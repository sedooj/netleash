# Support

Netleash is a hobby project maintained on a best-effort basis. There is **no support obligation, no guaranteed
response time and no roadmap commitment.**

- **Supported setup:** Claude desktop app + AmneziaVPN (Kill Switch **off**) on macOS 26. Everything else is unsupported.
- **Something broke in the supported setup:** open a [bug report](../../issues/new?template=bug.yml) and fill in the form
  completely (incomplete reports are closed). Never post personal data.
- **You want another app or VPN supported:** open a [feature request](../../issues/new?template=feature.yml) or add a 👍 to
  an existing one. Do not comment "+1" or "when?".
- **Security problem:** see [SECURITY.md](SECURITY.md); never use public issues.
- **Emergency:** if something goes wrong with your network, run `netleash panic` (or use the menu bar app) and then
  `sudo ./uninstall.sh`. See the README.
