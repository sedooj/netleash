Пусть приложение на Mac выходит в интернет только через VPN

Netleash — бесплатная утилита с открытым кодом для macOS, которая сажает выбранные приложения (Claude, Codex, Claude Code в терминале или любую программу) на сетевой поводок. Они выходят в интернет только через туннель VPN. VPN оборвался — ядро мгновенно отключает им сеть; вернулся — они подключаются сами.

Неофициальный, экспериментальный, без аудита. Не связан с Anthropic, OpenAI и Amnezia. Устанавливает root-демон и setuid-помощника — сначала прочитайте отказ от ответственности и ограничения. Сейчас поддерживается: AmneziaVPN с выключенным Kill Switch, macOS 26, Apple Silicon. Для Linux (amd64, arm64) есть экспериментальная сборка; Windows в планах.

Зачем

Обычный kill switch у VPN — «всё или ничего», и он часто гонится с фаерволом, который перезагружает. Иногда нужно, чтобы одно приложение никогда не показало ваш настоящий IP — например, ИИ-ассистент с агентами и встроенным браузером, — а остальной Mac работал как обычно. Netleash даёт такой kill switch для отдельных приложений без Network Extension и без прокси.

Безопасно при сбое

Разрешающее правило привязано к имени туннеля. Нет интерфейса — нет совпадения — пакеты отбрасываются, даже если демон упал.

Мгновенно, в ядре

Работает через pf macOS, а не опросом. Нет окна утечки при пропадании VPN.

Автоматическое восстановление

Когда VPN вернулся, правило переключается на новый туннель примерно за полсекунды.

Защита от утечек DNS

DNS VPN не запрашивается через физический интерфейс; пока VPN выключен и защищённое приложение запущено, весь DNS блокируется.

Оригинальные приложения не трогаем

Никаких копий, патчей и переименований. Необязательные подписанные ярлыки на рабочем столе сохраняют оригинальную иконку.

Открыто и проверяемо

GPL-3.0-or-later, релизы с контрольными суммами и подтверждением сборки, интерфейс на русском и английском.

Как это работает

Netleash запускает защищаемое приложение в отдельной группе _netleash. Якорь pf (1) пропускает loopback, (2) пропускает TCP/UDP только через интерфейс utunN VPN и (3) блокирует всё остальное. Root-демон следит за туннелем VPN и держит правило направленным на него; процессы защищаемого приложения, запущенные мимо лаунчера, завершаются примерно за 50 мс. Подробности и ограничения — в README.

Установка

Если хотите сначала прочитать скрипт, вариант 2 в README показывает, как проверить контрольную сумму и происхождение сборки.

curl -fsSL https://github.com/sedooj/netleash/releases/latest/download/get.sh | sh

Затем откройте Netleash, добавьте приложение, запустите его из значка в строке меню и проверьте:

netleash status   # взведена ли защита, жив ли VPN
netleash test     # принудительное соединение через физический интерфейс должно быть заблокировано

Требования

VPNAmneziaVPN, Kill Switch выключен (он перезагружает pf не атомарно и открывает окно утечки)
СистемаmacOS 26 (Tahoe), Apple Silicon · Linux amd64/arm64 с systemd и nftables (экспериментально) · Windows: в планах
ПриложенияПресеты Claude и Codex, любой оригинальный пакет .app или консольная программа вроде Claude Code (netleash apps add-cli claude)
Не покрытоICMP, приложения, запущенные мимо Netleash (они завершаются), вредоносный процесс с правами root

Вопросы

Как сделать, чтобы Claude на Mac выходил в интернет только через VPN?

Установите Netleash, добавьте Claude в его окне и открывайте Claude через Netleash. Claude и всё, что он запускает, работают в защищённой группе и могут использовать только туннель VPN.

Что будет, если VPN отключится?

Приложение сразу теряет сеть. Когда VPN вернётся, соединения заработают без перезапуска приложения; ответ, оборванный на середине, придётся отправить заново.

Это kill switch для отдельных приложений?

Да, для выбранных вами. Всё остальное работает как обычно.

Защищает ли он Claude Code в терминале?

Да: netleash apps add-cli claude, затем запускайте через netleash run claude или в netleash shell. claude, запущенный иначе, завершается.

Есть версия для Linux или Windows?

Linux (amd64 и arm64) есть, она экспериментальная: nftables и служба systemd. Windows в планах, ему нужен отдельный фильтрующий драйвер.

Работает с WireGuard, OpenVPN и другими VPN?

Пока не проверено. Сейчас поддерживается только AmneziaVPN; другие можно запросить в трекере задач.

Это безопасно?

Проект экспериментальный и без аудита, и он ставит привилегированные компоненты. Код небольшой и открытый: прочитайте его, проверяйте релизы и помните про аварийный откат netleash panic.

Как удалить?

sudo /usr/local/libexec/netleash/uninstall.sh
