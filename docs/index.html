Make a Mac app use the internet only through your VPN

Netleash is a free, open-source macOS tool that puts selected apps — Claude, Codex, Claude Code in a terminal or any program — on a network leash. They can reach the internet only through the VPN tunnel. If the VPN drops, the kernel cuts them off instantly; when it comes back, they reconnect on their own.

Download latest release View on GitHub
Unofficial, experimental, unaudited. Not affiliated with Anthropic, OpenAI or Amnezia. It installs a root daemon and a setuid helper on your Mac — read the disclaimer and limitations first. Supported today: AmneziaVPN with its Kill Switch off, macOS 26, Apple Silicon. Linux (amd64, arm64) is available as an experimental build; Windows is planned.

Why

A normal VPN kill switch is all-or-nothing and often races the firewall it reloads. Sometimes you only need one app to never touch your real IP — for example an AI assistant with agents and a built-in browser — while the rest of your Mac keeps working normally. Netleash gives you that per-app kill switch without a Network Extension or a proxy.

Fail-closed

The allow rule is tied to the tunnel interface name. No interface, no match, packets are dropped — even if the daemon has crashed.

Instant, in the kernel

Enforced by macOS pf, not by polling. No leak window when the VPN disappears.

Automatic recovery

When the VPN is back, the rule re-points to the new tunnel within about half a second.

DNS leak protection

VPN DNS is never queried over a physical interface; all DNS is blocked while the VPN is down and a protected app runs.

Original apps untouched

No copies, patches or renamed bundles. Optional signed desktop launchers keep the original icon.

Open and verifiable

GPL-3.0-or-later, checksummed releases with build provenance, Russian and English UI.

How it works

Netleash starts the protected app in a dedicated group, _netleash. A pf anchor then (1) allows loopback, (2) allows TCP/UDP only through the VPN's utunN interface, and (3) blocks everything else. A root daemon notices the VPN tunnel and keeps the rule pointed at it; processes of the protected app started outside the launcher are terminated within about 50 ms. Details and limitations are in the README.

Install

Read the script first if you prefer — option 2 in the README shows how to verify the checksum and build provenance.

curl -fsSL https://github.com/sedooj/netleash/releases/latest/download/get.sh | sh

Then open Netleash, add your app, launch it from the menu bar icon, and check:

netleash status   # is protection armed, is the VPN alive
netleash test     # a forced connection via a physical interface must be blocked

Requirements

VPNAmneziaVPN, Kill Switch off (it reloads pf non-atomically and would open a leak window)
SystemmacOS 26 (Tahoe), Apple Silicon · Linux amd64/arm64 with systemd and nftables (experimental) · Windows: planned
AppsClaude and Codex presets, any original .app bundle, or a command-line program such as Claude Code (netleash apps add-cli claude)
Not coveredICMP, apps launched outside Netleash (they are terminated), a malicious root process

FAQ

How do I make Claude use the internet only through a VPN on a Mac?

Install Netleash, add Claude in its window and open Claude from Netleash. Claude and everything it launches then run in the protected group and can only use the VPN tunnel.

What happens when the VPN disconnects?

The app loses the network at once. When the VPN is back, connections work again without restarting the app; a response interrupted mid-stream has to be resent.

Is it a per-app kill switch?

Yes, for the apps you choose. Everything else keeps its normal connection.

Does it protect Claude Code in the terminal?

Yes: netleash apps add-cli claude, then start it with netleash run claude or in netleash shell. A claude started any other way is terminated.

Is there a Linux or Windows version?

Linux (amd64 and arm64) is available and experimental: it uses nftables and a systemd service. Windows is planned and needs a separate filtering driver.

Does it work with WireGuard, OpenVPN or other VPNs?

Not yet validated. Today only AmneziaVPN is supported; see the issue tracker to ask for others.

Is it safe?

It is experimental and unaudited, and it installs privileged components. The code is small and public; read it, verify releases, and keep the netleash panic rollback in mind.

How do I uninstall it?

sudo /usr/local/libexec/netleash/uninstall.sh
